# AI Visibility Optimizer MVP

This is a simple MVP for a platform that helps companies optimize their visibility in AI search results.

## Tech Stack
- React
- TailwindCSS
- Vite

## Getting Started

### Install dependencies
```bash
npm install
```

### Start the development server
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

### Preview the production build
```bash
npm run preview
```

## Deploying
You can easily deploy this project on [Vercel](https://vercel.com/) by connecting your GitHub repository.

## Folder Structure
```
/public      # Static files
/src         # Source files
    /components/ui  # UI components
    AIVizMVP.jsx    # Main MVP app
    main.jsx        # Entry point
    index.css       # Tailwind setup
index.html         # HTML template
vite.config.js     # Vite configuration
```
